## 前提

| 記号                                    | 名前    | 説明                                                                      |
| ------------------------------------- | ----- | ----------------------------------------------------------------------- |
| $P^*$                                 | 命題集合  | あらゆる命題を内包する集合                                                           |
| $S^*$                                 | 選択子集合 | 命題$p\in P^*$から部分命題$p'\in P$を作成するために、命題$p$の一部を選択するための情報について、すべての組み合わせの集合 |
| $S: P^* \times S^* \rightarrow P^*$   | 選択写像  | 命題$p\in P^*$から部分命題$p'\in P^*$を抽出するために、選択子$s\in S^*$に基づき命題の一部を選択する写像     |
| $L: P^*\times P^*\rightarrow 2^{S^*}$ | 探索写像  | 任意の命題$p, q\in P^*$について、$S\left(p, s\right)=q$となるような全ての$s\in S^*$を求める写像  |

## 演繹推論
### 前提
| 記号                                                                 | 名前      | 説明  |
| ------------------------------------------------------------------ | ------- | --- |
| $G^D=\left(P^D,E^D\right)$                                         | 演繹推論グラフ |     |
| $P^D$                                                              | 命題集合    |     |
| $E^D\subseteq \left{\left(p, q\right)\|p,q \in P^* p\neq q\right}$ | 命題リンク集合 |     |
### グラフ構造
演繹推論では以下のような有向グラフを用いる。
- $p\in P^*$をノードとする
- $p$が、$p_1, p_2, ...\in P^*$からリンクされている時、$p_1, p_2, ...$全てが真、ならば、$p$が真である
