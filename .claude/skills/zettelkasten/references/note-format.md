# ノートフォーマット

## ファイル命名規則

`YYYYMMDDNN-slug.md`

- `YYYYMMDD`: 作成日
- `NN`: その日の連番（01〜）
- `slug`: タイトルの意味を表す英小文字のkebab-case

例: `2026060703-zettelkasten-minimum-unit.md`

## ファイル内容

```markdown
# タイトル

#タグ1 #タグ2

本文。本文。

## セクション名（任意）

内容。

```

## リンク記法

- `[[YYYYMMDDNN]]` — IDのみ参照
- `[[YYYYMMDDNN|表示テキスト]]` — 表示テキスト付き参照

## リンクの方向・配置

- リンクは本文の中で自然な流れで埋め込む。`## Related` セクションは使わない
- 抽象度の低い（具体的な）ノートから高い（抽象的な）ノートへリンクする
- A→B のリンクがすでに存在する場合、B のノートに B→A の逆リンクを設けなくてよい
